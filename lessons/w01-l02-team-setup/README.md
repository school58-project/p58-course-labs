## Цели

- освоиться в терминале: ходить по папкам, работать с файлами, потоками, правами и окружением
- руками пройти Git-цикл: clone → своя ветка → коммит
- поднять Python-окружение и запустить автопроверку первой лабораторной
- коротко посмотреть на роли в проекте и доску задач (подробно разберём на неделе 2)
- показать ментору у экрана вывод самопроверки `check_console.py`. Задания и как сдавать — в [`practice/console`](practice/console/README.md)

## Практика на уроке

Формат занятия: короткая презентационная часть + практические задания для самостоятельной работы на уроке.

1. навигация (`pwd`, `ls -la`, `cd`, `mkdir -p`): собери дерево папок проекта по образцу
2. файлы: `touch`, `cp`, `mv`, `rm`, `cat`, `less`, `head` / `tail`
3. потоки (`>`, `>>`, `|`, `grep`, `wc -l`): найди все TODO в файлах лабораторной 01
4. права и скрипты: `chmod +x` и свой `hello.sh`, который печатает аргумент
5. окружение: `which python`, `python --version`, переменная окружения, `history`
6. Git: `git config`, `git clone` репозитория курса, `git log --oneline`, своя ветка, коммит `about-<ник>.md`
7. Python-окружение: `python -m venv`, `pip install -r requirements.txt`, `python check.py` в lab01
8. бонус дома: `ssh-keygen` и ключ в GitHub. На учебном сервере это шаг 0 лабораторной 01: если сделал его во вторник, бонус у тебя уже есть

## Агентная разработка

Этап 0: агент только объясняет; код руками. Что можно спросить у агента: «что делает `ls -la`», «чем `>` отличается от `>>`», «почему `Permission denied`». Что делаешь сам: все команды заданий 1–8 вводишь руками, команды и скрипты из ответа агента не копируешь. `AGENTS.md` в lab01 (задача 7) тоже пишешь руками.

До конца декабря раздел лабораторной «Если используете агента» читаем по правилу этапа 0: агента можно спрашивать, что значит код или ошибка, но код пишем сами.
