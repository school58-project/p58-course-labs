## Цели

- понять, что мы строим за год: один большой проект, библиотеку браузерных мультиплеерных игр (идея с кикоффа). Вход через Telegram-бота прикрутим после Нового года
- разобраться в ролях проекта: фронтенд, бэкенд, игровая логика. Кто за что отвечает и к кому идти, если что-то сломалось
- освоить командный Git-процесс: issue → ветка → коммиты → pull request → ревью
- запомнить правило этапа 0: до конца декабря весь код пишешь руками, агент только объясняет

## Практика на уроке

Формат занятия: короткая презентационная часть + практические задания для самостоятельной работы на уроке.

1. нарисуй на листе путь игрока: браузер → сайт → сервер учётных записей → игровая логика. Красота не важна, важно, чтобы стрелки шли куда надо
2. возьми три issue из примера и придумай для каждой имя ветки и сообщение коммита по правилам проекта
3. выбери 2 роли, основную и запасную, и запиши их под своим ником

## Агентная разработка

Этап 0: агент только объясняет; код руками. Что спросить у агента: «чем ветка отличается от коммита», «что такое pull request». Что делаешь сам: настраиваешь Git и делаешь первые коммиты. `AGENTS.md` — файл с правилами проекта для агента, правило этапа 0 записываем туда же.
