# Урок 01. Кикофф: игры из Telegram, роли, Git-процесс

> Рабочая версия 1 (29.10.2026): план перерабатывается по итогам встреч менторов, часть решений на согласовании и может измениться.

**Неделя 1** (26.10–01.11) · Триместр 1 · Лекция · 3 академических часа

## Цели

- понять, что делаем за год: один большой проект — библиотеку браузерных мультиплеерных игр (идея из кикоффа); вход через Telegram-бота добавим после Нового года
- разобрать роли в проекте: фронтенд, бэкенд, игровая логика
- освоить командный Git-процесс: issue → ветка → коммиты → pull request → ревью
- узнать правило этапа 0: до конца декабря весь код пишем руками

## Практика на уроке

Формат занятия: короткая презентационная часть + практические задания для самостоятельной работы на уроке.

1. нарисовать на листе путь игрока: браузер → сайт → сервер учётных записей → игровая логика
2. для трёх issue из примера придумать имя ветки и сообщение коммита по правилам проекта
3. выбрать 2 роли (основную и запасную) и записать их под своим ником

## Агентная разработка

Этап 0: агент только объясняет; код руками. Спросить у агента: «чем ветка отличается от коммита», «что такое pull request». Руками: настроить Git и сделать первые коммиты. `AGENTS.md` — документ с правилами проекта, в него записываем правило этапа 0.
